Contact the Shopwise project

For technical problems, security concerns, or questions about the project, open an issue through the official source repository. Do not include passwords, access tokens, payment secrets, card details, or sensitive shop data.

Security reports

If a report contains sensitive security details, do not post secrets publicly. Provide only enough non-sensitive information to establish contact and describe the affected area.

Account and payment safety

Shopwise will never ask you to publish your password, API key, Stripe secret, webhook secret, or full card information in a support issue.
