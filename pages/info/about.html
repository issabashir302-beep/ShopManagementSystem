About

Software built around the daily work of a small shop.

Shopwise is an independent MiniPOS project designed to replace fragmented manual records with a clearer workflow for products, inventory, checkout, staff access, and reporting.

What Shopwise does

Owners can configure their shop, manage products and shopkeepers, monitor inventory, review sales, and receive monthly summaries. Shopkeepers receive a focused operational workspace without access to owner-only management reports.

How it is built

The application uses a browser-based frontend, a Node.js API hosted on Railway, and Supabase for authentication and persisted business data. Stripe supports card-payment processing and Resend supports transactional monthly report emails where configured.

Project status

Shopwise is an actively developed MiniPOS application. Some payment-provider features, including direct M-Pesa initiation and automated provider refunds, are not yet available and are not represented as completed services.
